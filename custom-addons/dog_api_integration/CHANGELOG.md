## [18.0.1.0.0] - 2024-12-16

### Added
- Initial release of DOG API Integration module for Odoo 18
- Automatic export of purchase orders to DOG system on confirmation
- Manual resend button for failed/existing orders
- Complete field mapping for all 26 DOG specification fields
- Support for two delivery modes:
  - Company Delivery (自社)
  - Direct Shipment to Customer (直送)
- Custom fields on purchase.order:
  - export_to_dog (Boolean)
  - dog_export_date (Datetime)
  - dog_export_status (Selection: pending/success/failed)
  - dog_export_message (Text)
  - x_delivery_mode (Selection)
  - x_ship_to_partner_id (Many2one)
- Custom field on purchase.order.line:
  - x_line_remark (Char)
- DOG Integration tab in purchase order form view
- Status filters in purchase order list view
- Comprehensive error handling and logging
- Japanese product name support (ja_JP context)
- Full address concatenation for ship-to address
- API authentication using Basic Auth
- Complete documentation (README.md)
- Test script for independent API testing
- Configuration file with customization options

### Features
- **Automatic Processing**: Purchase orders automatically sent to DOG API upon confirmation
- **Error Recovery**: Failed exports can be manually resent via button
- **Status Tracking**: Track export status, date, and API responses
- **Validation**: Pre-send validation of required fields
- **Logging**: Comprehensive server-side logging for debugging
- **Flexibility**: Support for both company and customer delivery scenarios

### Field Mappings
Complete mapping of 26 fields from Odoo to DOG:
1. order_seq - Internal DOG ID (auto-generated by DOG)
2. reg_date - Record creation timestamp (auto-generated by DOG)
3. po_number - Purchase order number (purchase.order.name)
4. po_line_number - Line sequence number (purchase.order.line.sequence)
5. order_date - Order date (purchase.order.date_order)
6. requested_date - Requested delivery date (purchase.order.line.date_planned)
7. buyer_code - Company partner reference (company_id.partner_id.ref)
8. buyer_name - Company name (company_id.name)
9. supplier_code - Supplier reference (partner_id.ref)
10. supplier_name - Supplier name (partner_id.name)
11. supplier_quote_number - Supplier reference (partner_ref)
12. delivery_destination_type - Delivery mode (x_delivery_mode: 1 or 2)
13. ship_to_party_code - Ship-to partner reference
14. ship_to_party_name - Ship-to partner name
15. ship_to_zip - Ship-to postal code
16. ship_to_state - Ship-to state
17. ship_to_city - Ship-to city
18. ship_to_street - Ship-to street address (combined)
19. ship_to_phone - Ship-to phone number
20. item_code - Product internal reference (default_code)
21. item_name - Product name (with Japanese context)
22. ordered_qty - Order quantity (product_qty)
23. unit_price - Unit price (price_unit)
24. line_amount - Line subtotal (price_subtotal)
25. po_remark - Purchase order notes
26. line_remark - Line specific remark (x_line_remark)
