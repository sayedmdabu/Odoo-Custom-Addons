DOG API Integration for Purchase Orders

Seamlessly integrate Odoo Purchase Orders with DOG System

Key Features

Automatic Export

Automatically sends purchase order data to DOG API when orders are confirmed. No manual intervention required!

Manual Resend

Easily resend failed or existing orders with a single click. Perfect for retry scenarios!

Complete Field Mapping

Maps all 26 fields according to DOG specification including:

  • Purchase Order Header Information (発注ヘッダ)
  • Order Line Details (発注明細)
  • Supplier Information (仕入先情報)
  • Delivery Destination (納品先)
  • Product Details (商品情報)
  • Pricing and Amounts (単価・金額)

Delivery Mode Support

Company Delivery (自社)

Standard delivery to your company warehouse or location.

Direct Shipment (直送)

Direct shipment to customer location with complete address details.

Status Tracking & Error Handling

Track export status with detailed logging:

  • Export Status: Pending, Success, Failed
  • Export Date: Timestamp of last export attempt
  • API Response: Detailed response or error messages
  • Filters: Filter orders by export status
  • Logs: Comprehensive server-side logging

Easy Configuration

Pre-configured and ready to use:

  • ✓ API endpoint configured
  • ✓ Basic authentication ready
  • ✓ Custom fields automatically added
  • ✓ No complex setup required
  • ✓ Works out of the box

Multi-language Support

Supports Japanese product names (日本語商品名) and translations. Automatically retrieves product names in the appropriate language.
