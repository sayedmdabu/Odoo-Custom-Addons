# Module Icon Instructions

## 📍 Put Your Icon Here!

Place your module icon in this directory:

**Filename:** `icon.png`
**Full Path:** `/path/to/odoo/addons/monthly_billing/static/description/icon.png`

## 📐 Icon Requirements

- **Format:** PNG (recommended) or JPG
- **Size:** 256×256 pixels
- **File Size:** < 100KB (recommended)
- **Name:** Must be exactly `icon.png` (lowercase)

## 🎨 Icon Design Ideas

For a Monthly Billing module, consider:

### Option 1: Invoice/Document
- 📄 Document icon with "請求" (invoice) text
- 🧾 Receipt/invoice symbol
- 📋 Billing document

### Option 2: Calendar-Based
- 📅 Calendar with "月" (month) character
- 🗓️ Calendar highlighting closing date
- 📆 Monthly view with currency

### Option 3: Financial
- 💰 Yen symbol with calendar
- 💵 Currency with document
- 💳 Payment/billing concept

### Option 4: Simple & Professional
- Blue background (#2c5aa0)
- White text: "MB" or "請求"
- Clean, minimalist design

## 📝 Quick Steps

1. **Create or download** 256×256 PNG icon
2. **Name it** `icon.png`
3. **Copy to** this directory
4. **Restart** Odoo server
5. **Update** Apps list in Odoo
6. **Done!** Icon appears in Apps menu

## Example Command:

```bash
# Copy your icon to this location
cp /path/to/your/icon.png /path/to/odoo/addons/monthly_billing/static/description/icon.png

# Restart Odoo
sudo systemctl restart odoo
```

## 🎯 What Happens Without Icon?

If no icon.png file is present:
- Odoo uses default placeholder icon
- Module still works perfectly
- Just less visually distinctive
